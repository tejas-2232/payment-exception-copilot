# P-02: Missing beneficiary name
Version: 1

Fictional training procedure. If the beneficiary name is missing, recommend that the analyst request the name through an approved channel. Do not guess the name.

Use this when the payment record has no beneficiary name. The analyst requests the name through an approved repair channel. A partner profile or a similar spelling in a note is not a substitute for the missing name. If two names are both present and disagree, use the conflicting-information review instead.
